## Editorial design (9 November 2026)
- The original Claude green-and-cream archive aesthetic is preserved.
- A 1.618:1 hero composition and a 13/21/34/55/89px spacing scale give the page a less repetitive rhythm.
- A small original isometric architectural motif, restrained curved accents, asymmetrical archival cards and gently irregular geometry add the requested Escher-adjacent character.
- Responsive layouts were checked at 1440, 820, 390 and 320px; reduced-motion users retain a static version.
